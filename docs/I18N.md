# Traductions

Les messages sont embarqués dans `src/client/src/design-system/i18n/messages/`.
**Ajouter une langue = ajouter un fichier** `<code>.json` (par ex. `de.json`) :
elle apparaît automatiquement dans le sélecteur de langue.

1. Copier `fr.json` (langue de référence) vers `<code>.json`.
2. Traduire les valeurs ; renseigner `language.name` (nom affiché, dans la langue)
   et `language.direction` (`ltr`, ou `rtl` pour l'arabe, l'hébreu…).
3. Garder les variables à l'identique (`{count}`, `{label}`…).
4. Pluriels : une valeur objet par catégorie de `Intl.PluralRules` de la langue
   (`zero`, `one`, `two`, `few`, `many`, `other`), `other` étant obligatoire.
5. `npm run test:client` : un test vérifie que chaque langue contient toutes les
   clés du français avec les mêmes variables.

Dans le code : `const { t } = useI18n();` puis `t('clé')`,
`t('clé', { variable })` ou `t('clé', 'texte de repli')`. Une clé absente
retombe sur le français, puis sur le texte de repli.

État actuel : la navigation, la barre supérieure, l'arbre et les Paramètres
sont traduits (français, anglais) ; les écrans métier sont encore en français
et migrent vers des clés au fil des évolutions.
